⚜️ Maison Noir — Luxury Tailoring Loading Page
📌 Aviso importante

Este projeto é uma obra fictícia e conceitual.
A marca Maison Noir não representa uma empresa real e foi criada exclusivamente para fins de estudo, design e experimentação de interface.

🧾 Sobre o projeto

A Maison Noir é uma loading page conceitual desenvolvida para simular a experiência digital de uma marca de alfaiataria de alto padrão.

O objetivo não é comercial, mas sim explorar como o design pode transmitir sensações de:

Exclusividade
Sofisticação
Poder visual
Minimalismo de luxo
🎨 Conceito visual

A interface foi criada com foco em uma estética de luxo silencioso (quiet luxury), utilizando:

Paleta de cores: preto profundo e dourado
Tipografia minimalista e elegante
Produto integrado ao fundo de forma atmosférica
Animações sutis e sofisticadas
🧠 Natureza fictícia

⚠️ A Maison Noir é uma marca totalmente fictícia.

Qualquer semelhança com marcas reais, nomes ou empresas existentes é mera coincidência.

Este projeto não possui vínculo com nenhuma empresa do setor de moda ou alfaiataria.
